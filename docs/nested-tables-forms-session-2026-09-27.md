## 채택한 변경

- **채점기(bench/compare-md-parsers.mjs)**: 파이프 칸 Markdown 이스케이프 해제, 영문자로 시작하는 태그만 제거(꺾쇠 글 보존), 칸 안 이미지·수식·링크 문법 제거(mdToPlain 과 같은 규칙), 암호 HWPX 짝 제외, `--exclude-single-col`.
- **HWP5 `flattenLayoutTables` 를 테두리 없는 표로 한정**: DocInfo BORDER_FILL 로 칸에 보이는 변이 있는 표는 풀지 않는다(`markBorderedTable`). 칸이 A4 용지보다 높은 표(여러 쪽 본문 상자)는 테두리가 있어도 푼다. 전면 해제는 기각 — rhwp issue3637 처럼 본문 전체를 9쪽짜리 테두리 상자에 담은 문서가 거대 HTML 표가 된다.
- **PDF 선 격자 중첩표(`splitNestedBoxes`)**: 끝점이 맞닿는(0.5pt) 선끼리 이은 닫힌 상자가 다른 틀 안쪽에 네 쪽 모두 틈을 두고 떠 있으면 `lineNested` 격자로 떼고, 소비측이 품는 칸의 blocks 에 넣는다. 이중 테두리(안쪽 상자가 네 쪽 모두 6pt 안) 제외. 중첩표를 품은 틀은 머리행·1열 레이아웃 필터와 산문 상자·차트 강등을 건너뛴다. 열린 아래 변 닫기는 같은 폭 표 여럿을 몸통마다 갈라 본다.
- **쪽 넘김 잇기 `restartsTitledForm`**: 전폭 제목 칸만 다르고 둘째 행 짜임·이름표가 같은 서식 상자는 새 표(tac-img-02 +4, 노인일자리 +2). 제목 칸은 40자 이하·항목 부호로 시작하지 않을 때만(form-002 이어진 조각 오분리 방지).
- **Markdown**: GFM 칸 span 줄바꿈 `<br>`, 캡션 안 표(`captionBlocks`) 표로 출력, v0.1 "첫 열만 값인 행 합치기" 제거.
- **양식 선택 상자**: HWPX `checkBtn`·`radioBtn` → "☐/☑ 캡션"(개체 폭 2,300 미만은 상자만 — 한컴 인쇄와 같게), 정답 추출기도 같은 규칙. PDF Marlett 체크박스 글리프 → ☐·☑.
- **#91**: XLSX·XLS 시트는 글 있는 행·열만 표로(병합은 남은 행·열로 축소), `KORDOC_MAX_UNZIP_MB`. **#92**: `includeFieldPlaceholders`(HWPX·HWP5·CLI·MCP).

## 기각·보류

- 열 경계 최소 폭 예외(서로 다른 행의 가까운 세로선 유지): 한국 표 효과 0 → 뺌.
- 가계동향(통계청 Distiller PDF) 35표: HWPX 정답이 표 밖 "(단위…)" 줄을 0행으로, 구성비·실질 칸을 머리 5행 격자에 엇갈려 둔다 — PDF 기하로 재현 불가, 보류.
- pii 규제 개요 24×11: cairo(rhwp) PDF 에서 열 구성이 다른 쪽 넘김 선 표를 합집합 격자로 잇는 기능이 필요, 실문서 생성기 아님 — 보류.
- 교육 통합 시험지 4문서(PDF 글 precision 0.35~0.40): PDF 수식 글리프가 본문 글로 잡힘(정답은 수식 제외) — 수식 영역 인식 필요, 보류.
- 행정업무운영 편람 중첩 3표: 가로 쪽 2쪽 모아찍기 서식 예시, 짝짓기부터 어긋남 — 보류.
